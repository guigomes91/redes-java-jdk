redes-jdk

Estudos de programação de redes com as APIs nativas do JDK: sockets, NIO, TCP, UDP, multicast e o Simple Web Server.

Visão geral

Cada classe do projeto é um exemplo autocontido, com seu próprio main. Nenhuma dependência externa: tudo usa java.net, java.nio.channels e com.sun.net.httpserver, que já vêm no JDK.

JDK 18+ obrigatório para o Simple Web Server (JEP 408). Os demais exemplos rodam em versões anteriores.

Simple Web Server (JEP 408)

Desde o JDK 18, o pacote com.sun.net.httpserver traz o SimpleFileServer: um servidor HTTP mínimo que só serve arquivos estáticos via GET e HEAD. Serve para protótipos, testes e para compartilhar arquivos na rede local. Não use em produção. 

HttpServer server = SimpleFileServer.createFileServer(
        new InetSocketAddress(8080),
        Path.of("./docs").toAbsolutePath(),   // precisa ser absoluto
        SimpleFileServer.OutputLevel.VERBOSE);
server.start();
  • O diretório precisa ser um caminho absoluto, senão é lançada IllegalArgumentException.
  • Requisições para / devolvem o index.html do diretório. Sem ele, o servidor gera uma listagem.
  • O Content-Type é deduzido pela extensão (esta página carrega style.css como text/css).
  • OutputLevel.VERBOSE imprime cada requisição com cabeçalhos no console.

A mesma coisa pela linha de comando, sem escrever código:

jwebserver -d C:\dev\git\backend\redes-jdk\docs -p 8080

Como executar

Pela IDE, rode o main da classe desejada. O caminho ./docs é resolvido a partir do diretório de trabalho, que precisa ser a raiz do projeto.

Pelo terminal, na raiz do projeto:

javac -d out src/caramelo/dev/sws/SimpleWebServerIntro.java
java -cp out caramelo.dev.sws.SimpleWebServerIntro

Depois, abra http://localhost:8080/.
